### 🔐 Bonnes pratiques sécurité

| 🔑 Principe | Application |
|---|---|
| Mots de passe | Hachage (bcrypt), jamais en clair |
| Injection SQL | Requêtes paramétrées via Eloquent ORM |
| Auth | Sanctum / sessions sécurisées |
| Contrôle d'accès | Rôles (admin / médecin / patient, etc.) |

> "La sécurité ne s'ajoute pas à la fin — c'est la première ligne de code."
